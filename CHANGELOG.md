# Changelog

## 1.0.1 — terminal-publication patch qualification

- Preserve consecutive-call admission when a result reaches the host before its
  native send settles, in both Python and TypeScript. Generation, cleanup, late
  delegated reply correlation and publication custody retain their boundaries.
- Add deterministic real-native-IPC regressions for the failing interleave.
  Issued `1.0.0` packages and native `0.7.0` artifacts remain immutable.

## 1.0.0 — package qualification

The SDK1 author contract is frozen for Python and TypeScript. Matching package
and installed-host qualification continues; see [the cohort guide](docs/sdk1-cohort.md).

- Application setup, readiness, settings, declared credentials, four I/O modes,
  invocation-scoped clients/discovery and durable inference jobs in both languages.
- Exact descriptor observations, authorized reads and inert proposals that
  preserve the original caller's permissions and cleanup ownership.
- Author tools0.2.0 and shared native0.7.0, retaining all14 existing profile
  meanings and every previously issued cohort identity.
- SDK1-compatible starter dependencies and checked package pins; reference0.2.0
  is a new SDK1 source version, preserving issued reference0.1.0.
- Maintained governed Python protocol-four/runtime-two interfaces. Native
  composition remains read/inference; proposals do not approve execution.

Native0.7.0 is published separately. Canonical SDK1/tools publication, matching
owner/runtime delivery and normal installed qualification have their own gates.
